# Banquillo

App para anotar en directo la estadística de nuestro equipo desde el banquillo, con informe por cuartos, e informes completos de cada partido.

- **App**: `https://guibanezbasket.github.io/banquillo/`. Ábrela en la tablet y usa "Añadir a pantalla de inicio": funciona sin conexión y guarda todo en el dispositivo.
- **Informes**: `https://guibanezbasket.github.io/banquillo/informes/`

## Cómo se usa
1. **Nuevo partido**: equipos, dorsales (del rival basta el número) y quintetos iniciales.
2. **Anotar**: toca jugador → acción. La app pregunta lo siguiente (asistencia, rebote, falta sobre quién, tiros libres). El reloj se arranca y se para tocándolo.
3. **Informe**: en cualquier momento, del partido o de cada cuarto: dónde perdemos, qué funciona, cuatro factores, comparativa, jugadores, quintetos y parciales.
4. **Partido → Exportar**: descarga un `.json`. Súbelo a la carpeta `data/partidos/` de este repositorio (Add file → Upload files) y en unos minutos aparece el informe completo en `/informes/`.

> Los jugadores son menores: usa solo dorsal y nombre de pila o iniciales, porque los informes publicados son públicos.
